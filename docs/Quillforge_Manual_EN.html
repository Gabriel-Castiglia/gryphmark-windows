1. What is Quillforge

Quillforge is a Markdown viewer and editor for Windows. You format text with buttons — headings, bold, lists, tables, code — and Quillforge writes the Markdown tags behind the scenes. Every document is shown exactly the way GitHub displays it, in light or dark theme.

It is designed for README.md files, notes, documentation and any .md file you want to read or edit without memorising syntax.

2. Installation

Run Quillforge-Setup-1.0.0.exe. The installer is available in English and Spanish and does not need administrator rights: it installs for the current user in %LOCALAPPDATA%\Programs\Quillforge.

OptionWhat it does
Desktop shortcutAdds a Quillforge icon to the desktop.
Open .md files with QuillforgeAdds Quillforge to Open with for .md / .markdown files, and makes it the handler for those files for the current user.

Requirements: Windows 10 or 11 (64-bit) and Microsoft Edge WebView2 Runtime, which is already part of Windows 11. The .NET runtime is included; nothing else has to be installed.

To uninstall: Settings → Apps → Installed apps → Quillforge → Uninstall. Your settings in %APPDATA%\Quillforge are kept.

3. The window

PartUse
Menu barFile, Edit, Format, View, Language and Help. All menus are available in English and Spanish.
ToolbarThe formatting buttons (see below). Hidden in GitHub preview, which is read-only.

The title bar shows the file name; a ● in front of it means there are unsaved changes.

4. Three ways to see a document

ModeShortcutWhat you see
Visual editorCtrl+1The formatted document. Type and use the buttons; the Markdown is generated for you.
Markdown sourceCtrl+2The raw Markdown on the left and a live preview on the right. For when you want to see or touch the tags.
GitHub previewCtrl+3Read-only page rendered like GitHub, with syntax highlighting, task lists and clickable links.

If you close a document with unsaved changes, Quillforge asks whether to save them.

Images and links

Relative paths work as on GitHub: ![diagram](img/diagram.png) shows the image stored next to the .md file. In GitHub preview, links to web pages open in your browser, links to other .md files open in Quillforge, and #heading links jump inside the document.

7. Export and print

Export to HTML saves a single, self-contained HTML page with the GitHub style embedded — ready to e-mail or publish.

Print / PDF (Ctrl+P) prints the GitHub-style page. Choose Save as PDF as the printer to create a PDF.

8. Language, theme and zoom

Language menu: English or Español. It changes the menus, the toolbar tooltips and dialogs immediately. The first time, Quillforge follows the Windows language.

View → Dark theme switches between GitHub light and GitHub dark. Zoom with Ctrl++, Ctrl+- and Ctrl+0. Language, theme, mode, zoom and window size are remembered.
